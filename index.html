單元 1

有超能力的飲料

🗣 先討論，再揭曉

和隔壁同學討論 2 分鐘：運動飲料、無糖綠茶、可樂、優酪乳、維他命水——哪些算「有超能力」的飲料？
寫下你們這組的判斷標準（要符合什麼條件才算）。先別往下按，討論完才揭曉！

食品科學家的標準只有一條：機能性飲料（functional beverage）是「除了解渴之外，還能提供特定健康益處」的飲料—— 裡面刻意加入或保留了維生素、礦物質、益生菌或抗氧化物等機能成分。 所以運動飲料、維他命水、優酪乳、無糖綠茶（有兒茶素）都算；可樂就不算。
對照一下：你們組訂的標準和科學家的一樣嗎？差在哪裡？

🫐 抗氧化物與多酚

水果裡的多酚（polyphenols）與類黃酮（flavonoids）是天然的抗氧化物（antioxidants）—— 能中和體內的自由基（帶有不成對電子、會攻擊細胞的活潑分子），減緩氧化壓力。 多酚含量的單位是 mg GAE/mL：GAE 是「沒食子酸當量」（Gallic Acid Equivalent）的縮寫， 意思是「換算成標準品沒食子酸，每毫升含幾毫克」——數字越大，抗氧化本錢越厚。 蔓越莓和葡萄是這門課的多酚資優生。

🌾 植物奶為什麼紅？

乳糖不耐、蛋奶素、環境足跡……讓米漿、豌豆奶、杏仁奶越來越受歡迎。 但植物奶要模仿牛奶的蛋白質含量和口感並不容易——這正是論文第二個案例要解的題： 怎麼把三種植物「混」出最高蛋白？

快速應用：你書包裡或早餐店那杯飲料，用剛才的定義檢查——是「機能性」的嗎？它主打什麼成分？

單元 2

食品的身分證：六個數字描述一杯飲料

🗣 先想像，再揭曉

你是飲料公司的品管員，要「用數字」向遠方的工廠描述一杯完美的果汁—— 不准用「好喝」「順口」「甜甜的」這種形容詞。
討論 2 分鐘：你會量哪些東西？每一種「喝得出來的感覺」（酸、甜、濃稠、會不會壞……）各要用什麼儀器、什麼數字表達？

科學家的清單是這六個——對照看看，你們想到了幾個？每個數字都對應一種你喝得出來的感覺：

pH 酸鹼值

管「酸不酸」（pH 源自拉丁文 potentia Hydrogenii，「氫的強度」，衡量氫離子濃度）。對數尺度：pH 每差 1，酸度差 10 倍。檸檬汁 pH≈2、果汁 pH≈4–5、牛奶 pH≈6.7。論文的果汁目標：pH 2.5–6。

°Brix 白利糖度

管「甜不甜」。以發明者白利（Adolf Brix）命名，表示可溶性固形物（溶在水裡的物質，主要是糖）占的百分比。手搖飲全糖約 10–12 °Brix，和論文果汁的目標區間 10–15 °Brix 剛好重疊。

黏度 η viscosity

管「濃稠感」——液體流動時的內部阻力。單位是厘泊（centipoise, cP）：水 = 1 cP，果汁約 20–26 cP，蜂蜜約 10,000 cP。植物奶要 40–80 cP 才有「奶感」。

密度 ρ density, g/mL

管「有多重」——每毫升的質量（克）。糖越多密度越高，所以果汁 > 水。混合物密度可以用各成分密度算出來（實驗室 A 就在用）。

水活性 aw water activity

管「會不會壞」。食品中「自由水」（沒被糖、鹽綁住的水）的比例，0–1 之間，微生物只能利用自由水。aw 越高越容易壞——果汁 ≈ 0.99，所以要冷藏；蜂蜜 ≈ 0.6，放很久也不壞。

總多酚 TP Total Phenolics

管「抗氧化實力」的計分板，單位 mg GAE/mL（見單元 1）。論文的合格線：TP > 500，並用 DPPH 測試驗證——DPPH（2,2-diphenyl-1-picrylhydrazyl，二苯基苦基肼）是一種人工合成的穩定自由基，飲料能「清除」掉越高比例的 DPPH，抗氧化力越強（合格線：清除率 > 70%）。

關鍵觀念：設計飲料 = 在這些數字的限制範圍內（別太酸、別太稠、別太稀），把你最在乎的那個數字（抗氧化力或蛋白質）衝到最高。這在數學上叫「約束最佳化」。

單元 3

配方的科學：理論派 vs 實驗派

要找出最佳配方，科學家有兩條路線：理論派——全部用方程式算，幾乎不進實驗室； 實驗派——真的調出幾十杯樣品逐一量測，再從數據找答案。

🗣 先猜，再揭曉

討論 2 分鐘，每組給出預測和理由：
① 哪一派的預測比較準？② 哪一派比較省時省錢？③ 如果又準又省，為什麼業界不全改用那一派？

📐 理論派 TMO

理論模型最佳化（Theoretical Model-based Optimization, TMO）： 把每個性質寫成方程式——密度用「倒數混合律」、pH 用「亨德森–哈塞爾巴赫方程式」（Henderson–Hasselbalch，用酸的解離程度估 pH）、 黏度用「格倫伯格–尼桑方程式」（Grunberg–Nissan，估混合液黏度的經驗式）——再交給電腦求解找最大值。 幾乎不用進實驗室，成本最低。
果汁答案：14% 蘋果、44% 葡萄、42% 蔓越莓 → 多酚 564.5

🧪 實驗派 DoE

實驗設計法（Design of Experiments, DoE）： 按「單體晶格混合設計」（simplex lattice mixture design，一種有系統地涵蓋所有比例組合的實驗排程） 真的調出一批不同比例的樣品，逐一量測後用迴歸分析（從數據反推出數學式）建立模型，再找最佳點。 較花時間材料，但貼近真實。
果汁答案：28.5% 蘋果、32.2% 葡萄、39.3% 蔓越莓 → 多酚 532

🗳 最終決戰：人的舌頭

兩種配方都調出來了，請 30 位受試者盲測（不知道自己喝的是哪一杯，避免先入為主）。 你猜——他們喝得出差別嗎？先投票再揭曉！

結局：兩種配方的評分（9 分制）是 7.7 ± 1.9 對 7.5 ± 1.2， 統計檢定得到 p > 0.05。p 值（p-value）是統計學用來判斷「差異是不是巧合」的指標： p 大於 0.05 代表沒有足夠證據顯示兩杯有差別——也就是喝不出來。 理論算出來的配方雖然不是完美精準，但消費者買單，還省下大量時間與食材。 這就是「電腦輔助食品設計」正在改變食品業的原因。

程式角落

自己算出最佳配方

模擬器背後只有一條多酚公式（論文式 9）。挑一個你熟的工具，把它輸入電腦，讓電腦找出最佳解—— 論文作者用的正是 Excel 規劃求解（Solver，Excel 內建的自動找最佳解工具），跟你要做的一模一樣。 

TP = 224.62·x蘋 + 606.16·x葡 + 600.54·x蔓 + 33.90·x蘋x葡 + 197.52·x葡x蔓 − 241.47·x蔓x蘋
（x 為質量分率，x蘋 + x葡 + x蔓 = 1）

Excel 規劃求解（和論文作者同款工具）

  1. 在 A1:C1 輸入標題「蘋果、葡萄、蔓越莓」，A2:C2 先隨便填三個比例（例如 0.3、0.3、0.4）。
  2. D2 輸入總和公式：=A2+B2+C2（等一下要限制它 = 1）。
  3. E2 輸入多酚公式：
=224.62*A2+606.16*B2+600.54*C2+33.9*A2*B2+197.52*B2*C2-241.47*C2*A2
  1. 開啟「資料 → 規劃求解」（若沒看到：檔案 → 選項 → 增益集 → 啟用「規劃求解增益集」）。
  2. 設定目標式 E2 →「最大值」；變數儲存格 A2:C2。
  3. 加入限制式：D2 = 1、A2:C2 >= 0、A2:C2 <= 1。
  4. 求解方法選「GRG 非線性」（GRG = Generalized Reduced Gradient，廣義簡約梯度法，一種一步步往更好答案移動的演算法）→ 求解。看看電腦找到的答案和科學家的 14/44/42 有多接近！

延伸：向老師索取「台灣食品營養成分資料庫（2025 版）」Excel 檔，可以查你最愛食物的真實營養成分。

Python（使用 scipy——Python 的科學計算套件）

import numpy as np
from scipy.optimize import minimize

def total_phenolics(x):
    a, g, c = x            # 蘋果、葡萄、蔓越莓的質量分率
    return (224.62*a + 606.16*g + 600.54*c
            + 33.90*a*g + 197.52*g*c - 241.47*c*a)

# minimize 找最小值，所以放負號 → 變成找最大值
res = minimize(lambda x: -total_phenolics(x),
               x0=[1/3, 1/3, 1/3],
               bounds=[(0, 1)]*3,
               constraints={'type': 'eq', 'fun': lambda x: sum(x) - 1})

a, g, c = res.x
print(f"最佳配方：蘋果 {a:.1%}、葡萄 {g:.1%}、蔓越莓 {c:.1%}")
print(f"總多酚：{total_phenolics(res.x):.1f} mg GAE/mL")
# 論文答案：14% / 44% / 42% → 564.5，你跑出來是多少？

R（網格搜尋——最直觀的暴力法）

tp <- function(a, g, c) {
  224.62*a + 606.16*g + 600.54*c +
  33.90*a*g + 197.52*g*c - 241.47*c*a
}

# 把所有可能比例（間隔1%）全部算一遍
grid <- expand.grid(a = seq(0, 1, 0.01), g = seq(0, 1, 0.01))
grid$c <- 1 - grid$a - grid$g          # 質量守恆：三者加總 = 1
grid <- grid[grid$c >= 0, ]
grid$TP <- with(grid, tp(a, g, c))

best <- grid[which.max(grid$TP), ]
cat(sprintf("最佳配方：蘋果 %.0f%%、葡萄 %.0f%%、蔓越莓 %.0f%%\nTP = %.1f mg GAE/mL\n",
    best$a*100, best$g*100, best$c*100, best$TP))
# 進階：R 的 NutrienTrackeR 套件可以分析真實食物的營養成分！

思考題：三個工具找到的「無限制」最佳解，可能是 100% 葡萄之類的極端配方。 回到實驗室 A 檢查——它能通過黏度和密度的限制嗎？這就是為什麼真實的食品設計是「約束最佳化」。
